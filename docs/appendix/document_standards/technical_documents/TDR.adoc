== Introduction

High-level standards defining the requirements and
considerations needed when designing a racetrack for the 
ODISC Ecosystem.

Track Design Requirements use the following numbering scheme:

[source,text]
----
TDR-NNN
----

Where:

* `TDR` identifies the document as a Track Design Requirement.
* `NNN` identifies the sequential Track Design Requirement number.

Example:

[source,text]
----
TDR-001 Size Requirements
----
