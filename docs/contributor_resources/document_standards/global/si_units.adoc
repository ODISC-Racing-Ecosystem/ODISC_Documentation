== Imperial Units

ODISC documents may also reference Imperial units (e.g., inches) for certain 
measurements, particularly in contexts where Imperial units are commonly used
or required by specific regulations. 

When Imperial units are used, they should be clearly indicated alongside the 
corresponding SI units to avoid confusion.
