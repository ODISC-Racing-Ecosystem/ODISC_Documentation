Below you will find the various technical specifications that exist for 
the ODISC Racing Ecosystem. Combined they provide the structure that 
defines the interoperability of the ecosystem to ensure that all the moving parts can work together.

* xref:TLG/index.adoc[TLG]: Technical Library Group, a collection of TLS that define a functioning system
* xref:TLS/index.adoc[TLS]: Technical Library Standards, specifications for how a single system works
* xref:DS/index.adoc[DS]: Domain Specification, the detailed specifications for how a TLS is implemented
