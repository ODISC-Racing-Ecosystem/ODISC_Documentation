== Introduction

This Domain Standard defines the foundational data primitives that all 
specification documents within ODISC shall share. By standardizing how we 
read letters, write names, and track time, we make sure that data looks 
identical whether it flows over a hardware radio or drops into a central 
database.

== Functional Requirements

=== Text Encoding
All text-based data payloads within the ODISC system shall use UTF-8 text 
encoding. Payloads shall not include a Byte Order Mark (BOM).

=== Naming Conventions
All data field keys shall use camelCase formatting rules. Key names shall 
start with a lowercase letter (e.g., `vehicleId`, `lapTime`).

All acronyms and abbreviations shall be treated as standard words for casing 
purposes, regardless of length. Only the first letter of an acronym shall 
be capitalized if it occurs at a word boundary (e.g., `controllerId`, 
`targetIp`, `htmlSnippet`, `useSsl`).

=== Dates and Timestamps
All date and time representations shall conform strictly to the ISO 8601 
combined date and time standard. Timestamps shall include the UTC offset 
or the `Z` (Zulu) designator to show timezone context clearly.
