== Introduction

This Domain Specification sets out the functionality of the Hardware 
Identification Dolly (hereafter the HID), an instrument used by the 
Race Management System (xref:../../../TLS/TLS-002/index.adoc[TLS-002]) 
to identify connected track components that lack moving parts.

== Physical Requirements

The HID resembles a regular vehicle, but lacks a motor. Wheels are optional, 
but can assist in moving the HID over track components to trigger the 
synchronization process.

The HID shall use a standard guide pin and braid pickup system as is found 
on any standard vehicle.

That said, a HID does not need to be a full-sized vehicle. It can be scaled 
down size-wise to the bare minimum required to contain the electronics.

== Functional Requirements

The HID shall contain a decoder and a transmitter diode placed directly 
over the slot. These can be a standard vehicle decoder that is set to 
an HID mode, or it can be a custom-designed decoder.

=== Transmit Synchronization ID

The HID does not actually need to decode anything. It is powered from the 
rails and transmits the predefined "Synchronization ID" to any sensor that 
is below it.

=== Power Rectification and Regulation

The onboard electronics shall tolerate up to a 24V nominal track power band. 
The internal power circuit must include regulation to step down voltage and 
withstand any data packets or other signal noise.

== Usage

During synchronization of hardware components with the Race Management System, 
the HID is moved across a sensor location to trigger the workflow of 
identifying it in the RMS.
