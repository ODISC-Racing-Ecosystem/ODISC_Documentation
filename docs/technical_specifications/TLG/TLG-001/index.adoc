== Introduction

The ODISC Global Website and Data Repository is the ultimate digital hangout 
and cloud-powered brain of the ODISC Racing Ecosystem. It is where drivers, 
clubs, tracks, and developers come together to share the racing love, track 
stats, and publish open standards.

While ODISC racing systems are built to run perfectly offline at your local track with 
zero internet beyond the initial setup phase, hooking up to the global ecosystem 
supercharges the experience. Connecting lets you automatically sync driver 
profiles, grab certified track layouts, download the latest firmware, and 
show off race results to the world.

Think of it as the ultimate pit-stop crew in the cloud, linking physical racing 
with global leaderboards and standards!

== Functional Areas

The Global Website and Data Repository is split into a few key areas, each 
defined by their own Technical Library Standards (TLS):

Global Web Portal::
xref:../../TLS/TLS-100/index.adoc[TLS-100] defines the public-facing 
website. It hosts the landing page, documentation for contributors, easy 
software downloads, and portals for drivers to manage their profiles.

Data Standards and Protocols::
xref:../../TLS/TLS-101/index.adoc[TLS-101] defines the "secret handshake" 
or common language that local tracks and global databases use to talk to each 
other cleanly, using nice and neat camelCase structures.

Global Registry::
xref:../../TLS/TLS-102/index.adoc[TLS-102] defines the data-handling 
muscle. It acts as the single source of truth for physical identities in the 
ecosystem, keeping track of clubs, drivers, venues, certified tracks, and 
vehicle profiles. It also handles the synchronization wizardry that keeps local 
tracks up to date.
