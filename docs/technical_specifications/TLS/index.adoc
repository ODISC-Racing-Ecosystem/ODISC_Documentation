= Technical Library Standards

The Technical Library Standards (TLS) define the standardized components,
capabilities, interactions, and responsibilities within the ODISC Racing
Ecosystem.

Each TLS covers a broad architectural scope while remaining narrowly focused
on its specific area of responsibility.
