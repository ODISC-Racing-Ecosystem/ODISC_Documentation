The purpose of this license is to allow broad access, use, implementation, and

== Definitions

ODISC Documentation::

Any document published by the ODISC Project, including specifications,
technical documents, design documents, architecture documents, guides,
manuals, reference materials, and other official documentation.

Official ODISC Documentation::

ODISC Documentation published by the ODISC Project and identified as an
official document.
